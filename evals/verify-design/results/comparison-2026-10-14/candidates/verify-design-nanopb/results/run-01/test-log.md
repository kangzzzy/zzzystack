# Nanopb 비교 시험 기록

2026-10-14. 독립 작성 에이전트가 data-design.md, examples.json, schema.sql, check.py 작성 후 사용량 한도로 중단됐다. 주 에이전트가 이어서 검사를 실행했다. 독립 완료 시험으로 집계하지 않는다.

실행: `python -X utf8 check.py`. 11개 unittest 통과(exit 0).

- 정상 메시지 5종, 필수 ID·길이·스키마 버전·정수 범위 검사.
- 측정 단위·범위·유효성·시각·배열 크기, UTF-8 길이 검사.
- 중복 JSON 키·NaN·잘못된 UTF-8·초과/잘린 프레임 거부.
- 역순 상태 무시, boot 변경 시 대조 필요 상태 반환.
- SQLite 유일성·참조 무결성·단계 제약, transaction rollback, 닫고 다시 연 저장소에서 UNKNOWN 전환 확인.

문서 검토 발견: 결과가 모두 일치한 복구 경로에서 현장 확인이 필수인지 불명확하다(REQ-06). 불일치 경로에만 현장 확인을 명시했다. 원본 산출물은 보존한다.

미검증: 독립 리뷰, 전체 명령 중복 실행 억제, 실제 전원 차단 내구성, 네트워크 분할 수신, 제어기 상태 대조/인증, Nanopb 생성기·C 컴파일·실장비. SQLite는 예제이며 DB 채택 결정이 아니다.
