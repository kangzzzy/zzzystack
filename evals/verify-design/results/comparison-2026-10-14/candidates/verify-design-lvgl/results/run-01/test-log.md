## 문서 검토와 미검증

원본의 위젯 상태 및 버튼 이벤트 예제와 코드 구조를 문서로 대조했다. LVGL 런타임은 설치/실행하지 않았다. HTML 시뮬레이션이며 실제 TCP/JSON 통신 또는 물리 동작 시험이 아니다.

브라우저를 실행하지 않아 화면 렌더링, 클릭 바인딩의 실제 브라우저 동작, 키보드·스크린리더, 모바일 레이아웃은 시각/상호작용 미검증이다. Node 검사는 순수 모델만 검증하며 UI 테스트로 간주하지 않는다.

미검증: ACK 유실의 실제 타이머, 동일 command_id 재수신 캐시, 역순 상태, 앱 재기동, 영속 저장/원자성/저장 실패, 개별 장비 FAULT 및 실장비 안전. REQ-15 전체 통과를 주장하지 않는다.

## 문제와 범위 제한

실행한 6개 검사에서 실패는 없었다. 잔여 결함은 design.md에 기록한 단일 사이클, 이송 완료 이외 복구 미구현, 세션 ID/메모리 이력 및 공유 가상 센서 한계다. 원본은 UI 위젯/이벤트 자료이므로 산업 제어 복구 정책을 직접 제공하지 않는다. 한 번의 최소 탐색 시험으로 종료하며 범위를 확대하지 않았다.
