# 정기·요청 보고

실행 조건: 설정된 보고 시각 또는 명시적 보고 요청. 현재 상태를 읽는 작업이며 개발·배포 승인을 확대하지 않는다.

프로젝트의 작업·Feature Map·검토·승인·자원 기록과 실제 상태를 확인한다. 출처가 오래되었거나 접근 불가하면 이를 표시한다.

보고는 완료·검증 결과, 현재 목표 대비 진행, 대기 결정·장애·한도, 측정된 자원, 다음 작업을 포함한다. 오전은 야간 결과와 당일 계획, 저녁은 당일 결과와 야간 계획에 집중한다. 누락 기간은 한 번에 통합한다.

주요 단계 종료 시 공통 원칙에 반영할 교훈 후보를 모은다. 승인 없이 공통 지침을 바꾸지 않는다. 결과는 현재 호스트에 반환하며 외부 전송은 승인된 채널이 있을 때만 한다.
