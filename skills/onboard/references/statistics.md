# 통계

데이터를 요약하거나 불확실성을 해석하는 방법을 배우는 요청에 적용한다.

## 설명 기준

- 무엇을 알고 싶은지와 어떤 데이터를 관측했는지를 먼저 구분한다. 필요한 경우 모집단은 알고 싶은 전체 대상, 표본은 실제로 관측한 일부 대상이라고 정의한다.
- 관측값의 요약과 모집단에 대한 추론을 구분한다. 평균·비율·분산 등은 무엇을 나타내며 단위가 무엇인지 설명한다.
- 확률이나 조건부 확률은 어떤 사건과 조건을 대상으로 하는지 명시한다. 조건이 바뀌면 같은 수치를 그대로 적용할 수 있는지 확인한다.
- 추정값을 설명할 때는 불확실성과 필요한 가정을 함께 다룬다. 신뢰구간의 신뢰수준을 계산된 구간에 모수가 들어갈 확률로 단정하지 않는다.
- 가설 검정은 귀무가설, 검정에서 사용하는 수치, 판단 기준 순서로 설명한다. p값을 귀무가설이 참일 확률로 설명하지 않으며, 통계적 유의성과 효과의 크기·실제 중요성을 구분한다.
- 상관관계나 회귀분석으로 인과관계를 바로 확정하지 않는다. 데이터 수집 방식, 다른 영향 요인, 모형의 적용 범위를 필요한 만큼 설명한다.
- 수식은 각 기호의 뜻을 먼저 밝히고 작은 수치 예제로 계산과 해석을 연결한다. 예시 데이터를 실제 조사 결과로 제시하지 않는다.

## 설명 순서 예시

표본평균을 배우는 요청이라면 관측 대상, 평균 계산, 그 값이 설명하는 범위, 표본이 달라질 때 생기는 차이 순으로 설명한다. 아직 필요하지 않은 검정 종류를 나열하지 않는다.
