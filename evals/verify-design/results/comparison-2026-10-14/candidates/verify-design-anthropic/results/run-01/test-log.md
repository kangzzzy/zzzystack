## 발견 및 수정

첫 실행은 상위 프로젝트의 ES module 설정 때문에 `.js` 내 require가 실패했다. 스크립트를 `.cjs`로 변경해 재실행했고 12개 시험이 통과했다. 상위 설정은 읽거나 수정하지 않았다. 구현 점검 중 DONE 이후 ACK 수신 이력이 소실되던 표시를 ack/done 개별 필드로 수정한 뒤 위 시험을 실행했다.

## 한계·미검증·남은 문제

- 실제 브라우저 렌더링, 스크린샷, 반응형 화면, 키보드 탐색, 스크린리더는 실행 검증하지 않았다. CSS 및 라벨은 구현했으나 접근성 합격으로 해석하지 않는다.
- 통신·센서·제어기·모터·안전 회로는 전부 가상이다. 실제 TCP/JSON 연결 및 물리 동작/안전 성능을 검증하지 않는다.
- 명령 중복과 역순 메시지 버튼은 해당 결과를 직접 시뮬레이션한다. 범용 메시지 파서, 실제 제어기 중복 방지 저장소, 다양한 순번/재부팅 epoch 조합은 구현하지 않았다. 시험 통과는 이 샘플 경로에 한정된다.
- 정상 heartbeat는 가상 1초 진행 때 자동 갱신한다. 실제 타이머, 동시성, 네트워크 지터, 지연 ACK, 부분 패킷, 장시간 부하 미검증. DONE 제한시간은 입력대로 미정이다.
- localStorage 단일 스냅샷은 시연용이다. 실제 디스크 충돌·강제 종료 내구성·다중 탭 경쟁·DB 트랜잭션 미검증. 명령 요청 저장 실패 시 발행은 막지만, 응답 상태 변경 후 저장 실패의 메모리 롤백과 재시도 복구는 미구현이다. REQ-11 전체 구현 충족을 주장하지 않는다.
- 역할 드롭다운은 인증/인가 보안이 아니다. 현장 확인 체크는 물리 증거가 아니다. 복구는 미완료 명령의 DONE 증거가 있는 단순 사례만 제공하며, 영구 결과 불명/폐기/수동 회수는 미정이다.
- D1 고장 원인 해소 입력은 IDLE을 주입하는 단순 가상 상태다. 생산 시스템에서는 실제 제어기 상태를 조회해야 한다. 화면 초기 공작물 상태/온도 역시 입력 시나리오이며 물리 추정이 아니다.

원본 frontend-design은 시각 계획과 자체 비평에 적용했다. 이 원본은 산업 제어 도메인 검증 및 위 미구현 항목의 해결 절차를 제공하지 않는다. Word/Excel/Figma 양식 적합성은 미검증이다.
