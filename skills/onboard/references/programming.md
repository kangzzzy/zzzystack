# 프로그래밍

프로그래밍 개념이나 작성·실행 방법을 배우는 요청에 적용한다. 특정 저장소를 파악하는 절차는 [코드·프로젝트](code.md)를 따른다.

## 설명 기준

- 언어와 실행 환경이 주어졌으면 그 기준으로 설명한다. 주어지지 않았으면 언어에 공통인 개념부터 설명하고, 구체적인 문법이 필요할 때 예시에 사용할 언어를 밝힌다.
- 문법, 실행 중 동작, 설계상의 선택을 구분한다. 한 언어의 특징을 모든 언어의 규칙으로 설명하지 않는다.
- 변수·자료형·함수는 담는 값, 허용되는 연산, 입력과 반환값으로 설명한다. 실행 순서와 값의 변화를 작은 예제로 확인할 수 있게 한다.
- 알고리즘은 해결할 문제, 입력 조건, 처리 순서, 출력으로 설명한다. 성능을 다룰 때만 입력 크기에 따른 시간·메모리 사용을 추가한다.
- 코드 예시는 해당 개념에 필요한 부분만 포함한다. 예상 출력과 이유를 함께 설명하고, 실제 실행 결과와 실행하지 않은 예상 결과를 구분한다.
- 오류를 설명할 때는 발생 조건과 원인을 먼저 밝힌다. 수정 전후의 동작 차이를 설명하되 요청하지 않은 기능 구현이나 환경 설치로 확대하지 않는다.

## 설명 순서 예시

함수를 처음 배우는 요청이라면 함수의 용도, 매개변수와 인자의 뜻, 반환값, 짧은 호출 예제 순으로 설명한다. 재귀·비동기 처리·메모리 구조는 해당 질문에 필요할 때만 다룬다.
