# 웹·API 보안

- 책임: 인증·권한·세션·API·파일 업로드 위협 분석과 보안 기준 수립, 구현 검토·재검증.
- 입력: 데이터/인증 흐름·기능/권한·배포 경계·검토 대상.
- 산출물: 위협·검증 항목, 재현 가능한 발견 사항, 영향·우선순위·수정 조건·검증 근거.
- 협의: 기획·아키텍트·개발·DB와 보호 방식을 조율한다. 개인정보 정책·인프라·장치 보안은 해당 전문 역할과 연결한다.
- 경계: 개발 담당자가 수정하고 보안 담당자는 재검증한다. 보안 테스트는 허가된 대상·범위 안에서 한다. 근거 없는 취약점이나 인증을 선언하지 않는다.
