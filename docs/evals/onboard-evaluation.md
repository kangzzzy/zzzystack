## 대상과 방법

Windows, Python 3.11.9에서 작은 CLI fixture (`tests/fixtures/onboard-todo/`, 0.6.0에서 백업 후 삭제)를 `.test-work/onboard-eval/todo project/`로 복사했다. 공백이 포함된 경로에 Codex·Claude용 묶음을 설치했다. 제품은 Python 표준 라이브러리만 사용한다.

서로 다른 평가 세션에 설치된 스킬과 대상 프로젝트만 제공했다. 제작자의 결론이나 기대 변경은 전달하지 않았다. 부모는 실행 로그의 출력·종료 코드와 파일 해시를 직접 대조했다. 상세 재실행 절차는 당시 `tests/evals/scenarios.md`(0.6.0에서 백업 후 삭제)에 있다.

## 평가 중 보완

최신 `knowledge-sources.json`만 갱신하면 과거 실행 보고서의 원본 해시 근거가 바뀔 수 있었다. 각 실행 폴더에 독립적인 `sources.json`을 보존하고, 갱신 전후 차이를 남기도록 절차를 보완했다. 이전 평가의 보고서·로그는 소급 수정하지 않았다.
