# Feature Map

대상 제품의 사용자·관리자·연동·백그라운드 기능 중 해당 범위를 포함하고 품질·보안·안전 요구를 관련 기능에 연결한다.

| ID | 기능·사용자/권한 | 입력·출력·상태·예외 | 관계·의존성 | 출시 범위 | 디자인·요구사항 | 수용 기준 | 작업 | 구현 상태 | 검증 상태·근거 | 출시 버전·근거 |
|---|---|---|---|---|---|---|---|---|---|---|

기능 ID는 변경해도 추적 가능하게 유지한다. 구현은 미착수/진행/완료, 검증은 미검증/실패/통과, 출시는 미반영/반영/철회로 구분한다. 기준 변경은 결정 기록과 연결한다.
