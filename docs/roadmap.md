# 개발 로드맵

- 목표: 24시간 자율적으로 작업하는 에이전트
- 방향: 자체 스킬과 ECC 등의 외부 개발 스킬을 agent workflow에 연결
- 현재: 사용자 검증 완료인 `i-have-adhd`, `requirements`는 `skills/`에 유지. 나머지 20개와 기존 README 후보 1개는 `evals/verify-*`에서 검증
- 아래 항목은 기존 목록을 옮긴 초안. 세부 범위·우선순위는 대화하며 확정
