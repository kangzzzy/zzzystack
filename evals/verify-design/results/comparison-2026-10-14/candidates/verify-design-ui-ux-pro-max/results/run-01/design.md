# 가상 셀 화면 설계

## 범위와 근거
확인된 입력은 requirements.md v1의 REQ-01~16이다. D1 가공 → R1 이송 → D2 가공을 관찰하는 작업자/유지보수용 데스크톱 웹 HMI다. 외부 의존성 없는 단일 HTML로 파일을 열어 탐색한다. 실제 제어·안전·현장 배포가 아니며 Word/Excel/Figma 적합성은 범위 밖이다. 설계 제안과 구현 한계를 아래에 분리한다.

## 화면과 조작 제안
1. 상단에 시뮬레이션 표기와 역할 선택을 고정된 첫 읽기 순서로 둔다. 역할 선택은 인증 기능이 아니다.
2. D1/R1/D2 카드에 상태 텍스트, 연결, 공작물, 문, 안전 입력을 표시한다. 미확정 상태는 마지막 관측이라고 표시한다. 정상 정보도 색상만으로 전달하지 않는다.
3. 사이클 영역은 단계·점유·차단 사유와 요청/ACK/DONE 명령 정보를 표시한다. ACK는 작업 완료가 아니며, 정상 DONE 모의 응답만 가공/이송 완료로 반영한다.
4. 장애·복구 영역에서 두절 → 재접속 → 제어기 조회 → 현장 확인 → 유지보수 확정 순서를 탐색한다. 확정 뒤에도 일시정지를 유지하고 배정 재허용을 별도로 요구한다.
5. 이벤트 영역은 순서가 있는 감사 기록이다. 페이지 메모리만 사용하므로 실제 영속 감사 로그가 아니다.

정상 탐색: 시작 → 다음 가상 응답 8회 → 완료. 각 장비는 요청 → ACK → DONE을 거치며 다음 장비 요청은 별도 클릭이다. 두절 탐색: 시작 → 다음 3회(R1 요청) → 통신 두절 → 재접속 → 조회 → 현장 확인 체크 → 작업자 복구 비활성 확인 → 유지보수 선택 → 복구 확정 → 배정 재허용 → 다음 응답. 두절 동안 점유를 유지한다. 조회 버튼은 명시적인 가상 제어기 응답으로 센서를 갱신하며 재접속 자체는 센서를 변경하지 않는다.

문/안전 입력 불량은 신규 명령을 막고 사유를 보인다. 진행 중 요청의 ACK/DONE 수신은 허용한다. HMI 일시정지가 물리 정지를 보장하지 않기 때문이다. 안전 동작은 독립 HW 책임이다.

## 시각 체계와 원본 기여
원본 스킬의 요구 분석 및 디자인 시스템 검색을 수행했다. search-design-system.txt의 최상위 패턴은 Real-Time / Operations Landing, 스타일은 Glassmorphism이다. 산업 HMI에 영업 CTA와 장식 효과는 부적합하다. 1회 좁힌 재검색(search-design-system-retry.txt)도 Hero + Features + CTA로 나와 검증된 HMI 패턴을 찾지 못했다. 결과는 시험 원시 로그로만 보존하며 MASTER로 채택/영속화하지 않았다.

재검색의 Minimalism & Swiss Style 중 대비·격자·간결한 위계, slate 색상은 일반 디자인 제안으로 참고했다. ux 도메인의 최상위 Disabled States는 비활성 버튼 표현에 직접 맞는다. 보조 검색의 회전 콘텐츠/애니메이션 결과는 적용하지 않았다. 일반 지침으로 비활성 사유 텍스트를 추가했다. 시스템 폰트, 16px 본문, 8/16/24px 간격, 44px 최소 버튼 높이, 3열에서 1열 반응형, 포커스 테두리, 네이티브 button/select/checkbox, 상태 live region을 사용한다. 외부 폰트·아이콘·GSAP는 채택하지 않았다. 원본의 모바일 safe area/Dynamic Type 기준은 데스크톱 웹 검증으로 대체했다고 주장하지 않는다. 전용 plain HTML 스택 검색이 없어 프레임워크 규칙은 사용하지 않았다.

## 시스템 경계(설계 제안)
PC [HMI ↔ 제어 서비스 ↔ 로컬 저장소]에서 제어 서비스 ↔ D1/D2/R1 제어기로 가상 TCP/JSON 명령/상태를 교환한다. HMI는 표시/의도 전달, 제어 서비스는 선행 조건/권한/점유/명령 기록, 각 제어기는 저수준 모터/로봇 경로와 실제 상태의 원본을 담당한다. 독립 안전 회로 → 각 장비 HW의 안전 차단을 수행하고 상태만 PC에 전달한다. 안전 링크의 실제 배선/프로토콜은 미정이다. 현재 HTML은 이 경계 전체의 축소 시뮬레이션으로 실제 프로세스 분리와 저장소가 없다.

미정: 실제 프로토콜·주소·레지스터·제어 주기·안전 정지 시간·장비별 DONE timeout·보존 기간·복구 판정 세부 절차. 공작물 초기 D1 있음/D2 없음은 정상 사이클 탐색용 설계 가정이다. 조회 결과를 이송 완료 1종으로 제한한 것은 최소 예제 범위이며 현장에서 결과 불명/미이송/부분이송을 자동 완료 처리해서는 안 된다.
